# Sales Data Analytics & Power BI Dashboard

## Project Overview

This project focuses on analyzing sales data to identify business trends, customer behavior, product performance, and profitability.

The project uses Python for data cleaning and analysis, SQL for data querying, and Power BI for interactive data visualization and dashboard development.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* SQL
* Power BI
* Jupyter Notebook

## Project Workflow

**Raw Data → Data Cleaning → Data Analysis → SQL Queries → Power BI Dashboard → Business Insights**

## Key Analysis

* Sales and profit trends
* Sales by category
* Profit by category
* Sales by customer segment
* Top 10 cities by sales
* Top customers
* Order and quantity analysis
* Customer and product performance

## Power BI Dashboard

The interactive dashboard includes:
